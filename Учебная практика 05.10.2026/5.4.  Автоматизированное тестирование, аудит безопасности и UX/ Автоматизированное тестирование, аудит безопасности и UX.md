# Автоматизированное тестирование, аудит безопасности и UX

## Задание
Финальный этап перед сдачей проекта. Приложение должно пройти стресс-тесты, проверку безопасности и быть готовым к обработке непредвиденных действий пользователя.

**Задача**:
  1. **Модульные тесты (Unit Testing)**: Напишите не менее 5 тест-кейсов на фреймворке тестирования для метода расчета материалов (проверка базового расчета, округления строго вверх, обработки некорректных ID и отрицательных параметров с возвратом -1).

  2. **Безопасность (SQL-инъекции)**: Проведите аудит кода. Все динамические запросы к базе данных (особенно текстовый поиск на главной форме или сохранение полей карточки) должны быть параметризованы. Прямая конкатенация строк в SQL-запросах запрещена.

  3. **Обработка исключений и MessageBox**: Защитите приложение от падений (`try...except` / `try...catch`). В случае ошибок ввода или недоступности БД выводите информативные `MessageBox` с иконкой ошибки и пошаговым руководством по исправлению для пользователя. При нажатии кнопки «Назад» (если данные изменены) выводите предупреждение о неотвратимости потери несохраненных данных.

  4. **Комментарии**: Напишите лаконичные поясняющие комментарии, но строго в тех местах алгоритмов, которые действительно неочевидны (например, логика округления или передача ID объекта между окнами фреймворка).
