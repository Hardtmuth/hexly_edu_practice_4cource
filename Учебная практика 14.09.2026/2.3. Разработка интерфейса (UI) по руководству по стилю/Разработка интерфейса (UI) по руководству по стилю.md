### Задание
Пользователю (менеджеру компании) необходим визуальный интерфейс для просмотра информации. Компоненты системы должны иметь единый согласованный внешний вид.

**Требования к UI из ТЗ**:
  - Заголовок окна/страницы должен четко соответствовать назначению (например: *"CRM: Список партнеров и скидок"*).
  - Установлена уникальная иконка приложения в углу окна (*из папки ресурсов*).
  - На главной форме отображается логотип компании (*из папки ресурсов*).

**Задача для студента**:
  - Разработайте экранную форму (с использованием `Tkinter/PyQt` для Python, `Windows Forms/WPF` для C# или `HTML/CSS` для Web).
  - Разместите на форме элементы: шапку с логотипом компании, текстовый заголовок и главный макет (таблицу или список карт) для вывода партнеров.
  - Настройте элементы управления (шрифты, цвета фона и кнопок) в соответствии с *"Screenshot_2"* .
