# Проектирование многооконной архитектуры и навигации

**Открыто с**: понедельник, 21 сентября 2026, 19:00  
**Срок сдачи**: суббота, 26 сентября 2026, 19:00

### Задание
Приложение должно перестать быть одностраничным. Необходимо настроить систему переключения экранов, которая позволит менеджеру перемещаться по приложению без потери состояния и аварийных завершений.

**Задача**:
  - Создайте в проекте структуру для двух окон/страниц: `MainWindow` (Главная форма со списком партнеров) и `PartnerEditWindow` (Форма добавления/редактирования).
  - Реализуйте механизм последовательного перехода между ними:
  - На главной форме добавьте кнопку *«Добавить партнера»*, которая открывает второе окно.
  - На форме редактирования добавьте кнопку «Назад» (или «Отмена»), которая закрывает текущее окно и возвращает пользователя на главную форму.
  - Обеспечьте для каждого окна индивидуальный уникальный заголовок (`Window Title`), строго отражающий его текущее назначение (например: *"CRM: Реестр партнеров"* и *"CRM: Карточка партнера [Редактирование]"*).
