# Написание DDL-скрипта (База данных в коде)

### Задание
Напишите SQL-скрипт (schema.sql) для развертывания спроектированной структуры

Инструкция к заданию
Скрипт должен содержать:
  - Команды удаления таблиц, если они существуют (DROP TABLE IF EXISTS...), с учетом порядка зависимостей.
  - Команды создания таблиц (CREATE TABLE) с правильными типами данных (VARCHAR, INT, DATE/TIMESTAMP, DECIMAL для цен).
  - Явное описание ограничений (PRIMARY KEY, FOREIGN KEY ON DELETE RESTRICT/CASCADE).
