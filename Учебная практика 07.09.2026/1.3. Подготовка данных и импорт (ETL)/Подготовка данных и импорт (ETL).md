# Подготовка данных и импорт (ETL)

### Задание
К заданию приложены файлы:
  - import_partners.csv
  - import_sales.txt

- Очистите предоставленные файлы от аномалий (дубликаты, некорректные форматы).
- Выполните импорт подготовленных данных в вашу СУБД.
- Разрешается использовать: команду COPY / LOAD DATA INFILE либо встроенные графические мастера импорта СУБД (DBeaver Data Import).
- Напишите проверочные запросы SELECT COUNT(*) по каждой таблице, чтобы убедиться, что все строки импортировались корректно.

### Форма ответа
.sql файл с импортом данных из приложеннх файлов

### Вопросы
1. Правильно ли я понял форму ответа?
2. В файле import_sales.txt в 5-й строке указан partner_id 4, но в файле import_partners.csv добавляется только 3 компании? самому что-то выдумывать? (в ответе поправил на существующий id)
3. Если нет, нужно ли писать скрипт для обработки всех типов файлов? (csv\txt)?
