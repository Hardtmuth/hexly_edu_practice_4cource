# Разработка проверочных SQL-запросов (Эмуляция бэкенда)

### Задание
Чтобы доказать, что база данных полностью покрывает бизнес-требования заказчика, напишите 3 SQL-запроса, которые будут использоваться будущим приложением.

Инструкция к заданию

Напишите скрипт queries.sql, содержащий:
- Запрос для вывода списка партнеров с сортировкой по названию и выводом общего количества сделанных ими доставок (используйте LEFT JOIN и COUNT).
- Запрос для добавления/обновления данных (демонстрация транзакции: создание нового партнера и запись о его первой тестовой доставке в рамках одного блока BEGIN...COMMIT).
- Запрос для истории реализации: вывод детальной истории отгрузок конкретного партнера за указанный период (с названиями продуктов, датами, объемами в штуках и итоговой суммой поставки).

### Форма ответа
.sql файл
