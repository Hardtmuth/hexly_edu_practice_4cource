# Разработка ядра алгоритма расчета материалов

**Открывается**: понедельник, 28 сентября 2026, 19:00

### Задание
Необходимо гарантировать точный расчет сырья для производства, исключив ручные ошибки менеджеров. Метод должен учитывать параметры изделия, коэффициенты типов продукции и процент брака материалов.

**Бизнес-логика метода**:
  - **Входные параметры (5 шт.)**:
    - `product_type_id` (int), `material_type_id` (int), `quantity` (int — количество продукции).
    - `param_1` (float), `param_2` (float — вещественные положительные параметры продукции).

  - **Логика расчета**:
    1. *Базовый расход на 1 ед.* = `param_1` * `param_2` * `Коэффициент типа продукции`
    2. *Общий чистый расход* = *Базовый расход на 1 ед.* * `quantity`
    3. *Итоговый расход с учетом брака* = `Общий чистый расход` * (1 + (*Процент брака материала* / 100))
    4. Результат округляется до целого числа в большую сторону (`ceil`).

  - **Обработка ошибок**: Если переданы несуществующие ID типов, отрицательные параметры или количество ≤ 0, метод должен **вернуть -1** (вместо падения программы).

**Задача**:
Напишите этот метод в коде приложения. Внутри метода реализуйте обращение к справочникам БД (или мок-объектам) для получения *коэффициента типа продукции и процента брака материала*.
